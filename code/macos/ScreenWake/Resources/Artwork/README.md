# ScreenWake artwork

* [app.svg](<app.svg>): detailed 1024 x 1024 transparent master for the app icon and promotional artwork. An amber retro cabinet, mint screen, antennas, smile, closed eyes, and rising zzZ establish the identity.
* [menu-off.svg](<menu-off.svg>): 24 x 24 transparent monochrome master with closed eyes and rising zzZ.
* [menu-on.svg](<menu-on.svg>): matching 24 x 24 master with very wide-open eyes and no sleep marks.

The menu pair shares identical cabinet, antenna, smile, feet, and controls. Black artwork and transparent negative space support native template tinting in light and dark appearances; do not add an opaque white background. Eye shape and sleep marks distinguish state without color. The native UI must select state artwork from confirmed observed protection, not a pending click.

These are original SVG source masters with vector sleep marks, no font dependency, and no external images. Native PNG, iconset, and `.icns` export belongs to the Rust `xtask` packaging work; these files alone are not a built app or installed icon. Pending/error presentation and menu interactions remain native integration work.
