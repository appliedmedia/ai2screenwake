# ScreenWake runtime

Exactly three runtime artifacts share one contract and one owner:

* [Backend](<ai2screenwake_backend/README.md>): feature-isolated contracts and Actions framework, without an unnecessary cloud service.
* [Client](<ai2screenwake_client/README.md>): owner policy and projections; future IPC/MCP.
* [Native](<ai2screenwake_native/README.md>): injected OS/host contracts; real implementations remain pending.

Build/test commands run from the repository root. The tooling-only `code/xtask` package is not a fourth runtime artifact. The root license is unchanged.
